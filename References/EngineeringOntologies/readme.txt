This archive contains:

- component-systems.pprj - ontology for modeling systems, decompositions of systems (part-of), connections between components in a system
- requirements.pprj - small ontology for modeling requirements (decomposition, derivation, constraints, etc.)
- constraints.pprj - ontology for modeling constraints on paths of objects
- EngineTransmission.pprj - an example ontology that uses the other ontologies

The ontologies are documented in the chapter 4 of the document:

http://opus.kobv.de/tuberlin/volltexte/2006/1437/pdf/tudorache_tania.pdf

Use cases using these ontologies are described in Chapter 6.

The ontologies can be opened with Protege frames (http://protege.stanford.edu).
